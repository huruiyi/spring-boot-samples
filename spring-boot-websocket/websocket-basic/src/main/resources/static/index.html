How it works

Set a username, then open a native WebSocket. A refresh always closes the socket (the TCP connection cannot survive). Username is kept in sessionStorage and the HTTP session (JSESSIONID); the page reconnects automatically. Disconnect clears that restore flag. Sending without a username is rejected.
