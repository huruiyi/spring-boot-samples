How it works

Set a username, then open a native WebSocket. Each window has two independent switches. Send broadcasts off = only you see what you typed. Receive broadcasts off = ignore other people. To picks Everyone (broadcast) or a nickname (private, only that person and you). The HTTP session (JSESSIONID) is shared in the same browser: switching to another tab of this app auto-connects. Disconnect only stops this tab. Username also survives refresh via sessionStorage.
