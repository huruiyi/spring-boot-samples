How it works

Set a username, then open a native WebSocket. Each window has two independent switches. Send broadcasts off = only you see what you typed. Receive broadcasts off = ignore other people. Other windows are not changed. Username survives refresh via sessionStorage / HTTP session; the TCP socket does not.
